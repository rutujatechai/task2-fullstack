# Task 2 - Full Stack Registration Form

## 📌 Project Description
This is a stylish registration form built using Node.js, Express.js, EJS, HTML, CSS, and JavaScript.

The project includes:
- Client-side validation
- Server-side validation
- Responsive UI
- Form handling

---

## 🚀 Technologies Used
- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

---

## ▶️ How to Run

1. Install dependencies

```bash
npm install
```

2. Start server

```bash
node app.js
```

3. Open browser

```bash
http://localhost:3000
```
